Turning the giveaway on or off

  1. Hostinger hPanel → Websites → moodpals.com → Node.js (Deployments) → Environment variables.
  2. Set GIVEAWAY_ENABLED, GIVEAWAY_ENTRIES_ENABLED and GIVEAWAY_CAMPAIGN_ID. Only the exact value true turns a switch on.
  3. Save, then Redeploy / Restart the app so the new values load.
  4. Check /api/giveaway and reload this page. The switches above show what the server is using now.

Emergency stop: set GIVEAWAY_ENABLED=false and redeploy. This hides the giveaway, blocks entries and holds giveaway emails. It keeps existing entries, subscriptions, Plus access and purchase emails. Turning it off is a technical stop, not a legal cancellation: the published Official Rules still apply.
